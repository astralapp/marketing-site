# Product

## Register

brand

## Users

Developers and technically-minded GitHub power users who have starred hundreds or
thousands of repositories and lost track of them. They live on GitHub, are
keyboard-comfortable, and have a low tolerance for UI friction.

On this site their context is **evaluative, not operational**: a developer arrives from
a link, search result, or social post and skims to answer four questions in under a
minute — _what is this, is it for me, is my data safe, what does it cost_ — before
deciding whether to connect their GitHub account. The job to be done is to understand,
fast, that Astral turns an unmanageable pile of GitHub stars into a searchable,
organized, annotated library — and to trust it enough to sign in.

## Product Purpose

Astral is a web app that organizes your GitHub stars with tags, notes, rule-based smart
filters, fast search, and an in-app README reader. It authenticates entirely through
GitHub OAuth (no passwords), is free and open source, and is self-hostable (Docker,
SQLite or MySQL).

This marketing site exists to convert evaluating developers into sign-ups by
demonstrating the product's value (surface any starred repo in seconds), surfacing the
trust signals that matter to this audience (open source, privacy, GitHub OAuth, no
lock-in), and conveying the product's calm polish. Success: a visitor understands the
product and clicks **"Get started — free"** with confidence.

## Brand Personality

Calm, focused, fast — a quiet power-user utility with a restrained astral/observatory
identity. Voice is plain, confident, and developer-to-developer: no marketing fluff,
clear over clever, honest about how it works. Three words: **calm, precise, cosmic.**
The emotional goal is _control and calm_ — the relief of a messy pile finally organized
and searchable — threaded with a little cosmic wonder (the Star Catalog).

## Anti-references

- **Generic dark dev-tool landing pages** (Linear/Vercel clones): dark canvas + one
  accent + a screenshot, with no point of view. We earn distinctiveness through the
  observatory / Star-Catalog identity, never by copying the SaaS-dark lane.
- **Cluttered, heavy enterprise tooling** — dense toolbars, nothing allowed to breathe.
- **Trendy / over-designed** — decorative gradients, gradient text, default
  glassmorphism, bouncy or elastic motion, effects for their own sake.
- **Childish or toy-like space theme** — cartoon rockets, sci-fi-game chrome. The
  cosmos stays subtle and adult, or it costs the trust of the developers who rely on the
  tool daily.
- **AI-slop tells** — a tiny uppercase tracked eyebrow above every section, `01 / 02 / 03`
  numbered section scaffolding, endless identical icon-heading-text card grids, the
  big-number hero-metric template, colored side-stripe accents.

## Design Principles

1. **Get out of the way.** Let the real product UI and a clear value proposition carry
   the page. Chrome, color, and motion stay quiet so the substance stays in focus.
2. **Earn the cosmos.** The astral identity is an accent that gives the page character —
   never a costume. Personality must never cost clarity or trust.
3. **Show, don't sell.** Prove the product with the actual app, real testimonials, and
   concrete answers (free, open source, private, no passwords). Demonstrate over persuade.
4. **Developer-to-developer honesty.** Plain language, no fluff. Be upfront about GitHub
   OAuth, what data is touched, and self-hosting.
5. **Consistency is craft.** The site should feel like the same hand that made the app —
   the same green, the same type, the same calm.

## Accessibility & Inclusion

Target **WCAG 2.1 AA**. Body text ≥ 4.5:1 and large text ≥ 3:1, verified on the dark
theme (muted grays included — no light-gray-for-elegance). Visible `focus-visible` rings
on every interactive element. Full keyboard navigation. Honor `prefers-reduced-motion`:
the starfield, hero float, and section reveals all have reduced or instant alternatives,
and no content is gated behind a motion-triggered reveal. Semantic HTML with proper
landmarks and alt text written in the brand voice.
